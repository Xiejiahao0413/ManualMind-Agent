# 空压机 A100 设备手册

设备名称：空压机 A100
设备型号：A100
适用范围：工业压缩空气系统的日常运行、故障诊断和维护。

# 故障码 E03 温度传感器异常

E03 表示温度传感器异常。控制器检测到温度传感器信号超出正常范围，可能导致温度读数不稳定、保护停机或过热报警。

可能原因：

- 温度传感器接线松动或端子氧化。
- 温度传感器探头损坏。
- 冷却风扇堵塞导致局部温度异常。
- 控制器采样通道异常。

排查步骤：

1. 先断电并等待设备冷却。
2. 检查温度传感器插头、线束和端子。
3. 清理冷却风道和风扇滤网。
4. 复位后观察 E03 是否再次出现。
5. 如 E03 持续出现，更换温度传感器并记录维修结果。

安全提醒：处理 E03 前必须断电、等待冷却，禁止带压拆卸温度传感器。

# 技术参数

工作温度：0-80 C。
额定电压：380 V。
工作压力：0.6-0.8 MPa。

# 安全注意事项

警告：维护前必须断电并挂牌锁定。
高温部件需要充分冷却后再接触。
禁止带压拆卸管路、阀门和温度传感器。
释放压力后应确认压力表归零。

# 维护周期

每日检查运行温度、压力和异常声音。
每 30 天清理冷却风道和过滤网。
每 90 天检查温度传感器线束、压力表和安全阀。
